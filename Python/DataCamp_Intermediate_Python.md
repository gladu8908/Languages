Intermediate Python


I completed the Intermediate Python course on DataCamp as part of my Python learning journey. This course helped me move beyond basic syntax and start understanding how Python is used in a more practical way for working with data, making decisions in code, visualizing information, and simulating real-world situations.

I came into this course already knowing the basics of Python, lists, functions, and introductory NumPy. What this course really did for me was connect those topics together and show me how they are used in larger, more meaningful tasks.

What I Learned
1. Data visualization with Matplotlib
In the first part of the course, I learned how to create and customize visualizations using Matplotlib.

Topics I practiced:

line plots
scatter plots
histograms
choosing the right type of plot for the data
adding labels and titles
adjusting ticks
changing marker size and color
adding grid lines
improving readability of plots
This section helped me understand that data is often easier to understand when it is visual. I also learned that different plots are useful for different purposes. For example:

line plots are useful for trends over time
scatter plots are useful for relationships between variables
histograms are useful for distributions


2. Dictionaries and pandas DataFrames
The next major section focused on dictionaries and pandas.

Topics I practiced:

creating dictionaries
accessing values in dictionaries
adding, updating, and deleting key-value pairs
nested dictionaries
converting dictionaries into pandas DataFrames
importing CSV files into DataFrames
setting row labels
selecting rows and columns from DataFrames
using square brackets, loc, and iloc
This chapter was important because it showed me how Python handles structured data. Before this, I mainly thought in terms of variables and lists. After this section, I started thinking more in terms of tables, rows, columns, labels, and organized datasets.

3. Logic, control flow, and filtering
Another major part of the course focused on decision-making in Python.

Topics I practiced:

comparison operators like ==, !=, >, <, >=, <=
boolean values: True and False
boolean operators: and, or, not
boolean operations with NumPy
if, elif, and else
filtering pandas DataFrames with conditions
selecting data based on logical rules
This section helped me understand how programs “make decisions.” It also made me more comfortable with reading conditional logic in Python, which is something I used to find confusing when the conditions got longer.

4. Loops
The course also covered loops, which helped me understand repetition in Python more clearly.

Topics I practiced:

while loops
for loops
looping through lists
using enumerate()
looping through NumPy arrays
looping through pandas DataFrames
building new columns in DataFrames through iteration
This section made looping feel much more intuitive. I learned not only how loops work syntactically, but also how they are used to process collections of data step by step.

5. Case study: Hacker Statistics
The final chapter brought many ideas together in a case study involving randomness, simulation, loops, and plotting.

Topics I practiced:

random number generation with NumPy
setting seeds for reproducibility
simulating dice rolls
using conditionals to update values
building a random walk
simulating many random walks
visualizing multiple simulations
plotting a distribution of outcomes
thinking about probabilities through simulation
This was one of the most valuable parts of the course for me because it combined several concepts into one project-like example. It showed me how Python can be used not just for isolated exercises, but for modeling situations and exploring outcomes.

Skills I Improved
By the end of this course, I felt more comfortable with:

reading Python code instead of only writing small pieces from memory
understanding how logic changes program flow
working with structured data using pandas
selecting and filtering data
creating basic visualizations
using loops more confidently
combining multiple Python concepts in one task
What Changed for Me
Before this course, I mostly understood Python in separate pieces:

variables
lists
simple functions
basic NumPy operations
After this course, I feel like I started seeing how those pieces connect.

For example:

data can be stored in dictionaries and DataFrames
logic can be used to filter and control what happens next
loops can repeat operations across data
Matplotlib can turn results into something visible
randomness and simulation can help answer real questions
That shift was important for me because it made Python feel more practical and less like a list of isolated rules.

Personal Reflection
One thing I noticed during this course is that understanding the why behind the code matters more than memorizing syntax. The more I practiced step by step, the easier it became to read code and predict what it would do.

I also learned that many concepts that looked difficult at first became manageable once I broke them down:

What data do I have?
What do I want to select or change?
Do I need a condition?
Do I need a loop?
Do I want to visualize the result?
That way of thinking helped me a lot.

Conclusion
Completing this Intermediate Python course was a meaningful step in my learning journey. It helped me build confidence with core Python concepts that are especially useful for data work, analysis, and problem solving.

I still have a lot to learn, but this course gave me a much stronger foundation in:

data handling
control flow
loops
plotting
simulation
Most importantly, it helped me become more comfortable reading and understanding Python code in context.
